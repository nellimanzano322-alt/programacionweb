Resumen de HTML: principales conceptos y etiquetas

Esta pagina va a resumir los principales conceptos y etiquetas visatas en la clase de programacion web 1, en el modulo de HTML

Conceptos principales de HTML

HTML

El lenguaje de marcado hipertexto es un lenguaje de marcas que se utiliza para estructurar sitios web

Elementos HTML

Un elemento HTML es la unidad basica de estructuras y contenido en una pagina web, y esta compuesta de :

  1. Etiqueta de apertura
  2. Pares atributos_valor
  3. Contenido
  4. Etiquetas de cierre

Etiquetas <Head>

Es una etiqueta que se utliza para comunicarse con el navegador a traves de los metadatos, permite mejorar el SEO, ademas se enlazan archivos externos de estilos o scripts

Etiqueta <body>

Dentro de esta etiqueta va todo el contenido que ve el usuario en nuestra pagina web

Contenedores semanticos

<Header> Es una etiqueta utilizada para el contenido introductorio de una pagina web, puede tener el logo, el menu de navegacion principal, el nombre de la empresa, etc
<NAV> Etiquetas utilizadas para el menu de navegacion, suele contener enlaces a otras paginas relacionadas o navegar por la pagina principal, no debe de haber mas de una pagina
<main> ETIQUETA UNICA DE LA PAGINA WEB CUYO OBJETIVO ES RESALTAR NUESTRO OBJETIVO O MENSAJE PRINCIPAL DEL SITIO WEB, DENYTRO SE COLOCARA EL CONTENIDO PRINCIPAL DE NUESTRA PAGINA
<section> Es una etiqueta que poco a poco se intenta que sustituya a <div>, su uso es para dividir a una pagina web en secciones y agrupar contenido relacionado
<article> Es una etiqueta que se utiliza para agrupar contenido autonomo, que si se separa de otro contenido sigue teniendo coherencia, normalmente se compone de un encabezado y contenido
<footer> Es una etiqueta que normalmente se encuentra hasta el final de una pagina y funciona como cierre del sitio web, a menudo contiene datos de contacto, derechos de autor u otra informacion complementaria
<aside> Esta etiqueta representa una seccion de la pagina web cuyo contenido no esta directamente relacionado con el contenido principal del documento, como: abrras laterales, publicidad, enlaces a otros articulos relacionados
